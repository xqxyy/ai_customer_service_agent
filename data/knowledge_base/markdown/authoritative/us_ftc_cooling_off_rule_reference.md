# 美国 FTC Cooling-Off Rule 客服参考

## 资料定位

- 文档 ID：us_ftc_cooling_off_rule_reference
- 适用地区：美国
- 业务领域：售后
- 风险等级：high
- 更新说明：该文档用于美国特定销售场景合规参考，具体适用性必须人工核验。

## 客服处理摘要

- Cooling-Off Rule 主要针对上门、工作场所、宿舍或临时地点等特定销售场景，不等于普通网购都能三天无理由取消。
- 用户提到上门推销、展会、酒店会议、临时摊位等购买场景时，应识别为高风险合规问题。
- AI 可以解释适用范围需要核验，但不能直接认定某笔交易一定适用或不适用。

## 标准处理步骤

- 确认销售发生地点、购买金额、商品/服务类型、签约时间和卖家是否提供取消通知。
- 如果可能涉及 Cooling-Off Rule，创建高风险人工审核工单。
- 要求用户保留合同、收据、取消通知、销售人员信息和沟通记录。
- 回复中说明将由人工根据交易地点、合同材料和适用规则核验。

## 回答边界

- 不能把 Cooling-Off Rule 解释成普通线上订单一律可三天取消。
- 不能给出法律结论或替用户起草法律文书。
- 不能承诺一定取消成功或一定退款。

## 人工升级触发条件

- 上门销售、临时地点销售、展会销售、宿舍/工作场所销售。
- 用户提到 Cooling-Off、三天取消、FTC、律师或监管投诉。
- 用户要求赔偿、撤销合同或投诉销售欺诈。

## 典型用户问题

- 美国上门推销买的东西可以三天内取消吗？
- Cooling-Off Rule 是否适用于普通网购？
- 销售人员没有告诉我取消权怎么办？

## 使用提醒

- 本文档是面向客服 Agent 的权威资料摘要，不是法律意见。
- 回答用户时应结合订单、商品、地区、平台规则和人工审核结果。
- 涉及投诉、赔偿、隐私、法律、监管举报等高风险事项时，应创建人工审核工单。
