# 中国个人信息保护与隐私请求处理参考

## 资料定位

- 文档 ID：cn_personal_information_reference
- 适用地区：中国大陆
- 业务领域：隐私
- 风险等级：high
- 更新说明：该文档用于隐私请求识别和人工升级参考，不替代平台正式隐私政策。

## 权威来源

- 中华人民共和国个人信息保护法（国家互联网信息办公室转载中国人大网法律文本，法律）：https://www.cac.gov.cn/2021-08/20/c_1631050028355286.htm

## 客服处理摘要

- 账号、手机号、地址、身份证明、交易记录等属于个人信息处理范围，客服回复应遵循最小必要原则。
- 用户要求查询、更正、删除、注销、撤回同意、投诉隐私泄露时，应进入隐私审核流程。
- 涉及未成年人、敏感个人信息、信息泄露、外部执法请求等场景时，AI 不能直接处理，应转人工。

## 标准处理步骤

- 先确认请求类型：查询、更正、删除、注销、解绑、撤回授权、投诉泄露。
- 涉及账号操作必须进行身份核验，不在公开对话中展示完整敏感信息。
- 隐私删除、数据导出、泄露投诉、未成年人信息处理，创建高风险工单。
- 回复中说明将按平台隐私流程和适用法律要求核验处理。

## 回答边界

- 不能在未核验身份时直接修改或删除账号数据。
- 不能复述完整手机号、地址、身份证件号等敏感信息。
- 不能对泄露责任作最终认定。

## 人工升级触发条件

- 用户称信息泄露、账号被盗、被冒用。
- 用户要求删除全部个人信息或注销账号。
- 涉及未成年人信息、敏感个人信息或执法机关请求。

## 典型用户问题

- 我要删除我的个人信息。
- 你们泄露了我的手机号怎么办？
- 我要注销账号并删除订单记录。

## 使用提醒

- 本文档是面向客服 Agent 的权威资料摘要，不是法律意见。
- 回答用户时应结合订单、商品、地区、平台规则和人工审核结果。
- 涉及投诉、赔偿、隐私、法律、监管举报等高风险事项时，应创建人工审核工单。
