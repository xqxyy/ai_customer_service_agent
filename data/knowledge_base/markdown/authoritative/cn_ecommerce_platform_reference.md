# 中国电子商务平台经营与订单履约参考

## 资料定位

- 文档 ID：cn_ecommerce_platform_reference
- 适用地区：中国大陆
- 业务领域：订单
- 风险等级：normal
- 更新说明：该文档用于订单履约和平台责任边界参考，具体处理以平台规则和订单状态为准。

## 权威来源

- 中华人民共和国电子商务法（共产党员网转载中国人大网法律文本，法律）：https://www.12371.cn/2020/06/11/ARTI1591822932213296.shtml

## 客服处理摘要

- 电子商务客服应区分平台规则、商家责任、物流责任和消费者操作问题。
- 订单取消、履约、支付、售后争议需要结合订单状态和平台协议处理。
- 平台类争议涉及经营者义务、平台协助、争议解决机制时，建议沉淀工单追踪。

## 标准处理步骤

- 先确认订单状态：待付款、待发货、已发货、已签收、售后中。
- 待发货订单优先按平台取消规则处理；已发货订单通常进入退货或物流拦截流程。
- 商家未履约、超时发货、页面承诺争议，应记录商品页面、订单时间和用户凭证。
- 平台责任或商家责任无法自动判断时，创建工单。

## 回答边界

- 不能在未读取订单状态时承诺可取消或可退款。
- 不能直接认定平台或商家违法。
- 不能绕过平台规则给出人工补偿承诺。

## 人工升级触发条件

- 用户称商家不发货、不履约、虚假宣传。
- 用户要求平台介入争议。
- 订单金额较大或涉及批量投诉。

## 典型用户问题

- 已发货订单还能取消吗？
- 商家一直不发货怎么办？
- 页面承诺和实际不一致怎么办？

## 使用提醒

- 本文档是面向客服 Agent 的权威资料摘要，不是法律意见。
- 回答用户时应结合订单、商品、地区、平台规则和人工审核结果。
- 涉及投诉、赔偿、隐私、法律、监管举报等高风险事项时，应创建人工审核工单。
